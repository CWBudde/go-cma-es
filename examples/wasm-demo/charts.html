Global versus generation best

The rose curve is monotone because it retains the incumbent. The amber curve is the best member of the current population and can rise. Their separation exposes ordinary fitness oscillation instead of hiding it.

Stopping has a state

TolX, TolXUp, the covariance condition limit, and no-effect checks read this distribution state directly. This is how CMA-ES stops a numerically exhausted run rather than spending a budget on motion too small to change the mean.
